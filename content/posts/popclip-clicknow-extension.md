Starting from 1.14.6, Clicknow provides a native [PopClip extension](https://github.com/laike9m/Clicknow/releases/download/1.14.8/clicknow.popcliptxt)! Once installed, it works just like another PopClip button. Here's how it looks like:

![](/blog/assets/uploads/c41cd887f76328d89a76907c42f4d74d.png)

PopClip Clicknow extension

## Installation

Installing the extension is super easy

1. Make sure you've installed [Clicknow](https://clicknow.ai) and [PopClip](https://www.popclip.app/);
2. [Download](https://github.com/laike9m/Clicknow/releases/download/1.14.5/clicknow.popcliptxt) the extension
3. Double click the downloaded file ***clicknow.popcliptxt*** to install

You should be able to see Clicknow appear as a PopClip extension 😀

![](/blog/assets/uploads/8a879fed8ce87a5d41fe4827bf1fb940.png)

## How do I disable Clicknow's popup, and only leave PopClip's?

Once you installed the extension, most likely you only want one popup.

You can do so easily but **turning off Clicknow** from the status bar, then you'll only see PopClip's popup. You can still use the extension and activate Clicknow as needed.

![](/blog/assets/uploads/c727de06d78b7555cc486e582a080bce.png)

## Do I still need the Clicknow app if I installed the PopClip extension?

First, **the PopClip extension just invokes the Clicknow app, so you still need to have Clicknow installed and activated**. I built the extension because many PopClip users asked for it, which is understandable as they only want one popup.

PopClip extension provides the two main features of Clicknow: **explain**, **translate**. But **the Clicknow app has several features that the extension doesn't cover**:

- Spell check
- Add date/time to calendar
- Flight tracking when selecting a flight number

If you don't use these features, then you can pretty much use the extension or native app interchangeably. For me, I prefer to use the app directly because I heavily use the spell checker.
