Clicknow is a unique AI tool as it comes with its own API key, and you can start using it right after download. By default, it uses Gemini to handle translation and explanation (and Perplexity for online searching). While this is handy, many customers still want to be able choose a different model and use their own API key.

Today, I'm happy to announce that this is possible. Starting **version 1.15,** Clicknow supports the following models:

- **GPT-4**
- **GPT-4 Turbo**
- **Claude 3.5 Sonnet**
- **Claude 3.5 Haiku**
- **Claude 3.7 Sonnet**
- **DeepSeek V3**
- **DeepSeek R1**

![](/blog/assets/uploads/f70acc1af8b331af643480e9ae22d619.png)

To use these models, **you need to provide an API key**.

If you want to use a model that's not in the list, please let me know in [r/ClicknowAI](https://www.reddit.com/r/ClicknowAI/) and I'll be happy to support it.
