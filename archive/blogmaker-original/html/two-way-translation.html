Clicknow is a handy tool for anyone who needs to work with foreign languages. Today, we're making Clicknow even more useful, introducing Two-way translation.

How It Works

Let's say you're a native Chinese speaker, but you need to work with English. Previously, you set "Translate to" to Simplified Chinese (简体中文). Now, you can set "Second language" to English

(Note: You can pick any two languages, not just Chinese and English)

Clicknow automatically detects the language when you perform text selection:

  1. If the selected text is not Chinese, it will be translate to Chinese (the "translate-to" language);
  2. If it is Chinese, it will be translate to English (the second language)

This allows people to work with their native and second language seamlessly.

Example

I'm still using Chinese-English as an example, but it works for any language combination.
